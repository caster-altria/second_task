9、底盘功率限制
功率限制的作用是在保证底盘总功率不超过限制的情况下，尽可能保留电机输出。
功率预测使用的公式如下
Pin = ∑(τ × ω) + K1 × ∑(τ²) + K2 × ∑(ω²) + K3

其中：
τ：电机期望力矩，单位为 N·m；
ω：电机实际角速度，单位为 rad/s；
K1：力矩相关损耗系数；
K2：转速相关损耗系数；
K3：底盘静态功耗；
Pin：预测输入功率。

当前功率计算使用输出轴参考系：

RM_Motor::speed
    ↓
输出轴角速度，单位为 rad/s

PID输出
    ↓
输出轴期望力矩，单位为 N·m

RM_Motor中间件会根据减速比13.7完成转子侧和输出轴之间的换算，具体使用的中间件有
sp_middleware/motor/rm_motor/rm_motor.hpp
sp_middleware/motor/rm_motor/rm_motor.cpp

当前临时参数为：
K1 = 2.0；
K2 = 0.01；
K3 = 5.0；
功率限制 = 60 W。
K1和K2是附件中给出的经验初值，K3和功率限制还需要根据实际测量结果进行调整。如果完整发送四个PID力矩后预测功率没有超过限制，则K = 1
四个电机直接使用PID输出。
如果预测功率超过限制，则假设四个电机力矩统一缩放：
τ实际 = K × τPID
将这个关系代入功率公式，可以得到关于K的二次方程：
aK² + bK + c = 0
解出满足功率限制的最大K，并将K限制在0到1之间。
K的含义如下：
K = 1：不需要进行功率限制；
0 < K < 1：功率超限，四个电机力矩统一缩小；
K = 0：本周期不发送电机力矩。
四个电机使用同一个K，包括反向制动力，保证功率预测使用的力矩和实际发送的力矩一致。
如果二次项接近0，则方程退化为一次方程。这样可以避免二次公式分母接近0时产生除零、无穷大或NaN。这属于数值保护，不改变正常情况下的二次方程计算。

applications/chassis_controller.cpp

pidLr.calc()
pidRf.calc()
pidRr.calc()
    ↓
calculate_power_scale()
    ↓
apply_power_scale()
    ↓

motorLr.cmd()
motorRf.cmd()
motorRr.cmd()

PID计算使用：

sp_middleware/tools/pid/pid.hpp
sp_middleware/tools/pid/pid.cpp

RM_Motor::cmd()负责把经过功率限制后的输出轴力矩转换为C620需要的原始控制量，应用层不直接拼接CAN数据。

功率限制只限制电机力矩，不会直接修改目标轮速。功率超限时，电机实际速度可能暂时跟不上目标速度。

以后增加自动模式时，自动模式也应经过同一条控制链：

自动控制器
    ↓
底盘目标速度
    ↓
麦轮解算
    ↓
PID
    ↓
功率限制
    ↓
RM_Motor
    ↓
CAN

自动模式不能绕过功率限制直接调用motor.cmd()。

当前功率限制仍需要实测确认：

1、K1、K2是否与当前输出轴参考系一致；
2、K3的实际静态功耗；
3、裁判系统规定的真实功率上限；
4、功率上限需要预留多少安全余量；
5、制动时负的τ×ω是否符合实际电源侧功率变化；
6、功率限制后底盘速度是否能够稳定跟踪目标速度。
