一、底盘代码运行线路
DBUS遥控器
    ↓
遥控器状态机
    ↓
得到 vx、vy、wz
    ↓
麦轮运动学解算
    ↓
得到四个目标轮速
    ↓
PID比较目标轮速和实际轮速
    ↓
RM_Motor生成电机力矩命令
    ↓
CAN1发送给四个M3508

具体而言：
1、dbus遥控器：
UART收到遥控器数据后调用remote.update(Size, stamp_ms);将18字节数据解析成：
ch_lv：前后；
ch_lh：横移；
ch_lu：旋转；
sw_r：右拨杆状态

2、状态机判断是否可以运动，具体见下文；

3、生成底盘速度：
进入ENABLED后代码对三个输入进行死区处理，然后乘以保守的最大速度
ch_lv → vx
ch_lh → vy
ch_lu → wz
此为底盘的速度指令，并非电机的具体速度！

4、麦轮解算
通过调用mecanum.calc(command_.vx, command_.vy, command_.wz);
根据mecanum中间件，它根据轮半径、半长、半宽，把底盘速度转换成左前轮目标速度、左后轮目标速度、右前轮目标速度、右后轮目标速度。
如果有某个轮子的速度超过上限，将会等比例缩小

5、can接受电机反馈
CAN1 收到电机反馈后，进入：HAL_CAN_RxFifo0MsgPendingCallback()
读取帧，再根据反馈 ID 判断是哪一个轮子；利用 RM_Motor::read()。RM_Motor 中间件负责把 C620 的原始反馈数据转换为实际速度，单位是 rad/s

6、pid控制；
使用pid中间件；

7、CAN 发送电机命令
PID 输出交给：motorLf.cmd(pidLf.out);
RM_Motor::cmd() 负责把力矩转换成 C620 所需的原始控制值。
然后：
motorLf.write(can1.tx_data);
can1.send(0x200);
应用层不直接拼 CAN 字节，全部通过 RM 电机和 CAN 中间件处理。

8、安全处理
以下情况会停止电机输出：
DBUS 掉线；
右拨杆为 DOWN；
尚未进入 ENABLED；
任意一个 M3508 反馈超时。
失能时会清除 PID，并让四个电机输出零力矩。这样即使任务循环还在运行，也不会继续给掉线电机发送有效力矩。
二、chassis_controller.cpp文件
1.现有功能
实现了遥控器状态机（失能，准备，和运行三个状态）
由状态机判断是否允许运动
Controller::update() 会判断：
a）遥控器是否在线；
b）右拨杆是否为 DOWN；
c）三个控制输入是否回中；
d）是否已经保持回中 200 ms。
当前状态流程是：
DISABLED → ARMING → ENABLED
UP 目前不做特殊处理，和 MID 一样允许运行，后面自动模式再区分

死区的判定（防止摇杆回中时由于某些原因抖动导致车子异常冲出）

速度的映射【（将摇杆输出的速度转化为底盘目标速度），最大速度和死区范围都采用保守值，可缩小死区范围以提高精度，或增大死区防止误触】

麦轮解算：根据底盘的目标速度拆解为四轮的角速度

PID，当前参数待调试，依次调试p，i，d的参数，p和i已设置最大输出上限；具体调试流程
1）先调试kp，根据串口助手，检测：电机反馈速度方向正确；目标速度和反馈速度单位都是 rad/s；四个轮子的正负方向正确；电机不会突然高速转动；PID 输出能够被 kWheelMaxOut 限制。后逐步增加kp，找到不明显震荡的kp。
具体调节注意事项：
目标轮速上升很慢，实际速度跟不上：适当增大 kp；
速度响应明显滞后，但没有振荡：继续小幅增大 kp；
电机出现周期性来回摆动：kp 太大，应降低；
电机发出明显啸叫或高频抖动：kp 过大，或者反馈噪声较大；
电机已经达到输出上限但速度仍然上不去：不是单纯增大 kp 能解决，而是 max_out 太小、目标速度太高或机械负载太大。（当前max_out为保守值，可逐步提高，但是不要提高到20A上限，约4.28N.m）
2）调节ki，已存在积分限幅，防止电机堵转或反馈异常时，积分持续累积，恢复后产生很大输出。为了消除稳定运行时的速度误差，应少量提高ki。
3）考虑ki，速度反馈来自 CAN，可能有量化和噪声。微分项对噪声比较敏感，所以不建议一开始就启用。

电机反馈处理线路如下
C620发送反馈帧
    ↓
CAN1接收中断
    ↓
sp::CAN::recv()
    ↓
根据rx_id匹配电机
    ↓
利用sp::RM_Motor::read()解析提取角度、速度、力矩
    ↓
更新 motor.speed、angle、torque
    ↓
PID使用 motor.speed 作为反馈值，根据实际速度与目标速度的差距，自动计算调整输出。

c620的反馈帧id为
电机 ID 1 → 0x201
电机 ID 2 → 0x202
电机 ID 3 → 0x203
电机 ID 4 → 0x204

C620 一帧反馈数据中主要包含：
DATA[0~1]：编码器角度
DATA[2~3]：电机转速 RPM
DATA[4~5]：实际电流原始值
DATA[6]：温度

电机在线情况由motorX.is_alive(now_ms)判断；
